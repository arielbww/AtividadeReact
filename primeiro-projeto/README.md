# Formulário React

Meu primeiro projeto em React! 

## Sobre

Atividade da faculdade: construir um pequeno formulário controlado com os campos **Nome**, **Email** e **Mensagem**. Ao clicar em **Enviar**, os dados digitados aparecem na tela, logo abaixo do formulário.

## Como rodar

```bash
npm install   # só na primeira vez
npm run dev   # abre em http://localhost:5173
```

## O que ele faz

1. Você preenche os três campos.
2. Clica em **Enviar**.
3. Os dados aparecem embaixo do formulário.

## Stack

- **React** + **Vite**
- CSS Modules (cada componente tem seu próprio estilo)
